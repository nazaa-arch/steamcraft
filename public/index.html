Arsitektur Sistem STEAM-Craft

Pilih Mode Operasional Aplikasi

Sistem ini mendukung 2 mode pengoperasian yang dapat dialihkan secara fleksibel:

🎯 Mode 1: Demo & Showcase Lomba Evaluasi Juri

Memuat 13 proyek riset multidisiplin terintegrasi (MIPA, Pendidikan, Sains Terapan), login cepat 1-klik akun demo, simulasi kendala (blocker), dan riwayat aktivitas terisi lengkap untuk demonstrasi kompetisi.

🚀 Mode 2: Operasi Riil Kampus / Produksi Live Deployment

Mode bersih siap operasional untuk universitas dan laboratorium nyata. Memerlukan autentikasi akun terdaftar asli, form registrasi mandiri, dan proyek riset riil yang dimulai dari awal.
